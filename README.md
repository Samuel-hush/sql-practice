# SQL 练习题集

## 这是什么
我整理的牛客网「SQL 快速入门」（tpId=199）练习，按知识点分类，共 42 题。

每个 .sql 文件按「题目 → 考察点 → 要求 → 涉及表 → 思路 → 笔记/心得 → 答案」记录，
是我刷题过程中边做边写下的笔记，方便回看思路和踩过的坑。

## 目录结构
- 01_基础查询/（5 题）
- 02_条件查询/（14 题）
- 03_高级查询/（5 题）
- 04_多表查询/（5 题）
- 05_常用函数/（10 题）
- 06_综合练习/（3 题）

## 覆盖知识点
SELECT / DISTINCT / LIMIT / AS、WHERE、= / > / BETWEEN / != / IS NOT NULL / AND / OR / IN / LIKE、ORDER BY、
MAX / COUNT / AVG / ROUND / GROUP BY / HAVING、INNER JOIN（多表）、UNION / UNION ALL、
IF / CASE WHEN、日期函数、SUBSTRING_INDEX、窗口函数、REGEXP、子查询、次日留存率、正确率

## 怎么用
每个 .sql 文件内包含：题目、考察点、要求、涉及表、分步思路、笔记心得、答案。

> 注：题目按牛客网「SQL 快速入门」官方题单整理。表 user_profile / question_practice_detail / question_detail / user_submit / contacts / daily_profits 为题库自带。
> 其中 SQL40 / SQL41 / SQL42 及 SQL6、SQL32 的字段与口径需以牛客原题为准。
